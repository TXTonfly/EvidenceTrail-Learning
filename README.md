# EvidenceTrail

**An independent software-engineering learning challenge — 2026–2027**

**Status:** Planning / Assignment 001 not yet submitted  
**Development environment:** Omarchy Linux  
**Initial language:** Python  
**Goal:** Build the skills to independently design, develop, test, and demonstrate a small software project before pursuing HackUTD 2027, subject to eligibility.

## What is EvidenceTrail?

EvidenceTrail starts as a simple command-line application that records a scientific claim and a source, then presents a clear summary. Future versions may add multiple records, user-entered evidence assessments, local file storage, tests, and a simple interface.

The first versions **do not automatically evaluate scientific truth**. Assessments, if added, are entered by the user and clearly identified as such.

## Learning agreement

1. The learner writes every line of implementation code and types all commands.
2. AI may explain concepts, provide hints, review submitted work, and grade exercises, but **must not generate or silently edit implementation code**.
3. Start small; prioritize understanding, debugging, and clear reasoning over speed.
4. Keep this project separate from AXIORYTH company code, SI Core protected research materials, frozen evaluation artifacts, and held-out datasets.
5. Verify HackUTD 2027 rules and participation eligibility when organizers publish them. This is an independent project, **not an official HackUTD challenge**.
